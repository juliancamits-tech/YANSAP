# Analyzer Rules (Draft)

## MOD001

Contracts projects cannot reference other projects.

## MOD002

Contracts projects cannot install forbidden implementation packages.

## MOD003

Modules cannot reference other Modules.

## MOD004

Only Bootstrap may be public inside a Module.

## MOD005

Contracts projects must remain dependency-free except approved base dependencies.

## MOD006

Contracts projects cannot reference other Contracts projects.
